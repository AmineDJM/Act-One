# Fonts for the synthetic film

DejaVu Sans (Book) and DejaVu Sans Bold, unmodified, from DejaVu Fonts 2.37
(Debian `fonts-dejavu-core`). Distributed under the Bitstream Vera licence
with DejaVu's changes in the public domain; see `LICENSE-DejaVu.txt`.

They are here so the synthetic film the analyzer is tested against is the
same film on every machine. Rendered with whatever face a host happens to
have, its type — and so what OCR reads and every measurement of type
geometry — would differ from one machine to the next.
